# 本地控制台（macOS）

在 Mac 上运行本地代理，在浏览器中管理文件、编辑 UTF-8 文本并执行终端命令。运行时无需云服务器、账号或外部服务，无第三方 npm 依赖。

## 本地启动

1. 安装 **Node.js 22 或更高版本**，将本项目下载并解压到 Mac。
2. 在终端进入解压后的项目文件夹，运行：

   ```bash
   node server.mjs --root "$HOME/Documents"
   ```

   将 `--root` 改成希望管理的文件夹。也可以运行 `bash start-macos.command`，按提示输入目录；路径含空格时直接粘贴，不添加引号。若 macOS 提示目录权限，请允许终端访问所选目录。

3. 在浏览器地址栏手动输入终端显示的本机地址（默认 `http://127.0.0.1:4317`）。将终端中的临时配对码粘贴到网页，点击连接。
4. 浏览文件、编辑文本、保存时确认覆盖；可以新建文件和文件夹。命令栏输入 `pwd`、`ls -la` 等命令，确认后执行。
5. 在代理终端按 **Control+C** 关闭服务。重启后配对码会改变。

端口被占用时添加 `--port 4318`。无需执行 `npm install`。

## 权限与行为

- 仅监听 `127.0.0.1`，从同一台电脑浏览器访问。API 要求配对码并检查同源请求；配对码仅存于网页内存，刷新需重新配对。
- 文件接口拒绝目录外路径和外部符号链接。仅支持不超过 1 MB 的 UTF-8 文本；新建不会覆盖已有文件。保存会覆盖内容，不提供版本恢复，请避免同时在其他程序修改正在编辑的文件。
- **终端命令拥有当前本地账户权限，工作目录限制不构成命令沙箱。** 命令可访问账户可访问的其他位置，执行前网页会确认。不要以管理员身份启动，也不要运行来源不明的命令。
- macOS 使用 `/bin/zsh -c` 运行一次性命令；这不是交互式登录终端，可能没有日常终端的别名或 PATH 设置。必要时使用工具绝对路径。一次仅执行一条命令，30 秒超时，输出最多 1 MB。命令结束、超时或输出过多时清理进程组；不用于持久服务、交互式 `sudo` 或 SSH 会话。
- 页面断开连接只清除配对状态；已提交的命令可能继续到完成或超时。关闭代理终端才能停止服务。
- 当前版本提供本机浏览器控制，不提供其他设备远程接入或屏幕、鼠标、键盘控制。

## 开发与验证

```bash
npm test
```

测试启动真实 HTTP 代理，在临时目录验证文件读写、认证、同源检查、路径与符号链接边界、命令退出状态、超时、输出限制和并发保护。没有构建步骤。

实现和 8 项自动测试在 Linux / Node.js 24 上通过；Chromium 中已验证配对、文件编辑保存、执行命令、断开连接和窄屏布局。macOS 系统权限提示、Safari 界面和 zsh 分支仍需在 Mac 上实际验证。本项目不会取消或删除平台上的既有云环境，后续运行可完全在本地完成。
